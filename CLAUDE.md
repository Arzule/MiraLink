## Notas de sesión
MiraLink es un MVP para probar viabilidad técnica del control del cursor con la mirada. El usuario hace las pruebas manuales con cámara, pantalla y cursor real; el agente escribe el código y solo verifica con tests y scripts sin hardware (nunca abrir la cámara, iniciar el control del cursor ni registrar el hotkey global real). Nunca afirmar verificación visual o con hardware que no se hizo: usar "no verificado". Commits locales por etapa, sin push. Persistir en AGENTS.md toda decisión de diseño nueva.
